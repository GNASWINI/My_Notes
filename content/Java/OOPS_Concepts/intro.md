# Java OOPs Concepts

Object-Oriented Programming (OOPs) is a way of writing programs using **objects** and **classes**.  
The 4 main pillars of OOPs are:

1. [Encapsulation](encapsulation.md)  
2. [Inheritance](inheritance.md)  
3. [Polymorphism](polymorphism.md)  
3. [Abstraction](abstraction.md)  

Each concept is explained with **real-world examples** for clarity.
